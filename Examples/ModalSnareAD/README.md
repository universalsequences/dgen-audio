# ModalSnareAD — differentiable VILLAIN-style snare renderer (E1)

A closed-form, frame-parallel, batched `[B, K]` snare renderer in DGenLazy:

- **Head** (`Head.swift`): VILLAIN Snare's analytic modal bank, mode for mode — amplitude,
  decay, attack, onset `t0`, phase, and exponentially decaying pitch glide (`g`, `tau`, phase
  integrated in closed form), the Nyquist fade, the head and drum gates (GH/GD) and
  `head_v`. It matches the instrument's head stem to < 7e-4 relative RMS on all 156 dataset
  renders (`parity`).
- **Noise/wire** (`SnareModel.swift`): 16 fixed, precomputed band-noise signals
  (`e1/noise_bands`, generated by `e1/make_noise_bands.py`; the filter bank is data and
  matches the realtime spec `e3proto/NOISE_BANDS.md`), each scaled by a closed-form
  two-stage envelope (attack, fast decay, tail level and decay), plus a head-coupled term
  `C_b * E(t)` with `E(t) = sqrt(sum_k env_k(t)^2)` (wire buzz driven by the head).
- **Output stage**: VILLAIN's drive mix `x + d_amt (tanh(dv x) d_norm - x)`, the length fade
  and the output gain. All parameters are bounded (log/sigmoid maps).

Data comes from the eseq research workspace (`ESEQ_MODAL_AD_ROOT`, default
`~/code/learning/anthropic/eseq/.local/research/modal-autograd`).

```bash
swift build -c release --product ModalSnareAD
B=.build/release/ModalSnareAD
$B parity --ids all                                  # head vs stems/*.head.wav
$B fdcheck --head true                               # FD vs autograd, MSE loss, all groups
$B fdcheck --head true --loss spectral               # same with MR-STFT loss
$B fit --steps 400 --lr 0.03 --freeze-output always --init <e1>/noise_init.json --out <dir>
$B physfit --lambda 0.01 --out <dir>                 # Bessel-structured head vs head stems
```

`fit` trains B = 32 snares in one batched pass (MR-STFT lin + log, windows 128–2048,
hop w/4) against `out.wav`, and writes per-snare `*.fit.wav`, `*.target.wav`,
`*.fit_headpart.wav`, `*.fit_noisepart.wav`, `summary.json`, `params.json` and `loss.csv`.
